NewsMuncher Phase 4G — reduce repetition without losing the humour
Date: 2026-10-12

Scope and safety
================

This work extends the successful local Phase 4F configuration without changing
defaults. It used deterministic local generators, explicit semantic metadata,
mocked article uptake and in-memory state. It made no provider request, MongoDB
connection or production write and did not inspect historical creations.

The evaluation setup remains:

  NEWSMUNCHER_EXPANDED_VOCABULARY=evaluation
  NEWSMUNCHER_EXPANDED_DESCRIPTORS=evaluation

Phase 4G is independently enabled with:

  NEWSMUNCHER_COMEDY_SEMANTIC_MEMORY=evaluation

Unset that variable or set it to `off` to retain Phase 4F behaviour. The new
flag does not enable expanded names, slang or fictional places.

Confirmed sources of repetition
===============================

1. Exact phrase cooldowns were working. Different high-quality phrases still
   reused the same descriptor mechanism, subject family or name sound family.
2. Accepted concept memory already had the strongest coverage: exact phrase,
   base object, semantic premise and independently introduced animal species.
   Applying another concept-mechanism penalty reduced quality of the whole
   candidate slate: Phase 4F rolling-ten premise repetition rose from 63.54 to
   66.63 and object reuse also worsened. That selection experiment was rejected.
3. Descriptor Phase 4F diversification sampled broadly, but it had no memory of
   which broader mechanisms had recently survived into final text. Subjects
   caught exact forms, while close wording such as competitive/professional
   queueing could escape.
4. Invented names have ample exact combinations but comparatively few broad
   consonant/vowel sound families. Exact-name cooldown therefore cannot prevent
   a run of names that sound structurally alike.
5. Slang and place repetition is unchanged. Phase 4F proved the experimental
   generators inferior to the live CSV banks on short windows, so Phase 4G does
   not route them into the live rewrite path.
6. Offered ingredients and final articles are separate measurements. A provider
   may ignore, paraphrase or independently invent a joke. No selection change
   guarantees the final prose will use its improved distribution.

Implementation
==============

The new `semantic_memory.py` supplies stable family keys, timezone-safe recency
penalties and accepted-family updates. Family history shares the existing Mongo
collections and accepted-use lifecycle. It creates no new database connection.

Descriptor memory records two explainable identities when the accepted article
provides evidence:

* comic mechanism, such as secret history, medical restriction or domestic
  supernaturalism;
* semantic theme plus a conservative lexical head, so competitive queueing,
  professional queueing and national queueing resolve to
  `secret_history:queueing`.

The lexical matcher uses only an explicit normalized anchor of at least four
letters, handles simple plural endings, and ignores the family when the source
article already contained that anchor. It does not attempt fuzzy similarity.

Descriptor assembly applies recent-family history after grammar, category,
intensity, within-slate mechanism diversity and the short-form preference. The
penalty affects order only. It never rejects a candidate and therefore cannot
create exhaustion.

Invented-name selection stores a category plus normalized vowel/consonant sound
family. Recent accepted families sort behind fresher families. Every candidate
has already passed the existing pronunciation, safety and minimum-quality
checks. Exact name cooldown and active name leases remain hard.

Concepts record accepted mechanism families for diagnosis, but Phase 4G leaves
their Phase 4F ordering unchanged. Existing phrase, base, premise and animal
memory remains authoritative. This is an intentional result of the quality
gate, not an unfinished integration.

All family writes occur only after a successful rewrite has been persisted and
only for accepted evidence. Failed requests and unused offers release their
normal leases and add no history. Genuine retries retain deterministic slates;
new rewrite UUIDs obtain fresh deterministic pools.

Humour and naturalness gate
===========================

An early family-first ranking looked diverse but reduced mean descriptor quality
from 7.911 to 7.717 and increased mean length from 6.48 to 8.18 words. It also
worsened concept prompt metrics. Both changes were rejected.

The final ordering retains grammar, quotas, within-slate mechanism balance and
the short-form preference before semantic recency. Across 100 quality samples,
mean descriptor quality was 7.900 versus 7.911 for Phase 4F; mean length was
6.69 versus 6.48 words. The small movement is acceptable for local evaluation,
but manual spoken review remains required before promotion.

Examples of repetition now related by explicit keys include:

* banned from competitive queueing / suspended from professional queueing;
* speed topiary / competitive topiary secret-history variants;
* repeated medical-prohibition constructions with different clinicians;
* names with different spellings but the same cheeky or absurd sound skeleton.

Examples deliberately not suppressed include strong concepts whose mechanism
penalty harmed prompt quality, source-required animals, and independently
invented provider jokes for which no offered metadata supplies reliable proof.

Performance and reliability
===========================

The uncached audit measured average local generation at 379.82 ms live,
439.45 ms for Phase 4F and 437.79 ms for Phase 4G. Average prompt characters
were 1,594.05, 1,574.60 and 1,594.59 respectively. Phase 4G added about 1.3%
over Phase 4F prompt characters and no provider slots or calls.

The audit estimated 18,250 local database operations for live and Phase 4F and
20,500 for Phase 4G across 250 rewrites. The increase represents bounded writes
for accepted families. Candidate availability still uses the existing batched
read. All three configurations completed 250 rewrites with zero controlled
exhaustion and zero within-prompt duplicate premise violations.

Hard safeguards remain unchanged: exact cooldowns, active leases, fresh rewrite
UUIDs, stable retries, accepted-use-only history, failure cleanup, typed HTTP
409 exhaustion and timing instrumentation. Family saturation only changes sort
order and cannot make a slate unavailable.

Final-article evaluation limits
===============================

The fixture distinguishes exact text, ingredient identity, premise identity and
joke mechanism. It proves the selector exposes a less repetitive accepted-input
sequence under fixed uptake. It cannot prove a language model will follow every
offer, recognize an untagged paraphrase or refrain from inventing its own repeated
callback. Real local MUNGEs must be reviewed before this flag is promoted.

Recommended next steps
======================

Run at least twenty real local MUNGEs in alternating Phase 4F and Phase 4G blocks.
Read them aloud and label repeated premises separately from exact wording. Keep
Phase 4G evaluation-only unless that review confirms fewer repeated jokes without
weaker punchlines. Expand explicit premise aliases only from observed false
negatives; do not add fuzzy matching, embeddings or model calls. Retain the live
CSV slang and place paths until their experiments beat live short-window results.
